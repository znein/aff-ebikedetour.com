Speed & the law

E-bike classes and Kingbull speed settings

Most US states sort e-bikes into three classes, and the class decides where you can ride. Here's how Kingbull's 20 and 28 mph settings fit in.

The three classes

ClassMotor helps whenAssist stops at
Class 1Pedaling only20 mph
Class 2Pedaling or throttle20 mph
Class 3Pedaling (throttle rules vary)28 mph

Class 3 bikes are often kept off multi-use paths and trails, and many states set a minimum age or require a helmet for them. Rules differ by state, city and park, so check where you'll ride.

Where Kingbull bikes sit

  • Top speed: most Kingbull models reach 28 mph with pedal assist; the throttle alone stops at 20 mph.
  • Ships at 20 mph: Literider 2.0, Discover 2.0, Discover ST 2.0, Trekker, Verve come set to 20 mph and can be adjusted between 5 and 28 mph.
  • Dual Battery Voyager 2.0: Kingbull lists Class 3 as the default with a Class 2 option.

Set to 20 mph, these bikes behave like a Class 2 e-bike (throttle plus assist to 20 mph). Unlocking 28 mph puts them in Class 3 territory, and the throttle-only limit stays at 20.

Speed costs range

Air resistance rises steeply with speed, so riding at 28 mph uses noticeably more battery than 20. Try both settings in the range calculator.
